## 3. Core evidence disciplines preserved

1. **Market boundary**：仅讨论 `consumer crypto/stablecoin → real-world purchasing power`；Card 是 rail，不是市场。
2. **Evidence class separation**：Market/Data Fact、Decision、Proposal/Hypothesis、Inference、Unknown 分开；不把战略选择写成外部事实。
3. **No current→target leakage**：current AIX 仅使用 Step 5 reviewed baseline；目标 Money Account、stablecoin-primary、unified/no-manual-prefund 均不得反写为现状。
4. **No synthetic TAM**：L1/L2/L3 不相加；tracked card figures 是 observed sample，不是 TAM；品牌 volume 不进入总盘。
5. **Job separation**：J1/J2/J3 证据不串层；J1 Primary 是战略选择 / Inference，不是 proven demand ranking。
6. **Direct four-AND**：same current region + same core Job + overlapping starting money + substitutable purchasing-power outcome；不要求 same X/Y/custody/rail。Step 3 `Direct candidate` 与 Step 4 竞争 taxonomy 不混用。
7. **KAST conflict**：保留 X2 confirmed / Y Unknown / Cluster Unknown / Money Account；Step 2 `X2×C / S3` 已被 supersede。
8. **Eligibility discipline**：Unknown ≠ No；future/waitlist ≠ current；merchant acceptance ≠ issuance/service eligibility；aggregate ≠ country。
9. **Rail discipline**：QR Ph / BSP 只支持 rail maturity，不支持 stablecoin/crypto usage；Card commodity、Money Account retention、local rails moat 都保持 Inference。
10. **Region / white-space caveat**：PH 仅为 current evidence best-supported proof market；WS-1 仅为 Low–Medium confidence candidate，非 confirmed blue ocean。
11. **Strategy boundary**：A6→A3→A1 是 staged path；A2 是 capability；A4/A5 是 future options。Stablecoin-primary 是 market-level proposal，不得漂移为 fiat-native neobank。
