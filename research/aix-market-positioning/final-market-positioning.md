## 1. Executive conclusion

市场不是 Crypto Card，而是 **consumer crypto/stablecoin → real-world purchasing power**：消费者如何把 Crypto / Stablecoin 转化为现实世界购买力。AIX **不应被定位为另一张 Crypto Card**；Card 是必要 rail，但不是产品身份。

**Target Proposal：Stablecoin-native Everyday Money Account。** 核心不是“多一张能花币的卡”，而是让稳定币成为能持续接收、持有、转移并通过多种 rail 使用的日常资金。

> **AIX = Stablecoin-native everyday money：收得到、存得住、转得走、随处花。**

## 2. Market map

| Job | 用户购买的结果 | 当前证据与战略角色 |
|---|---|---|
| **J1 Global Money** | 一种稳定、可跨境、能持续收 / 存 / 转 / 花的钱 | 账户方向和玩家样本存在，但用户量化不足。**AIX Primary Job 是战略选择 / Inference，不是已证明的需求排名。** |
| **J2 Crypto → Spend** | 已持有 Crypto / Stablecoin，低摩擦变成现实购买力 | **当前样本中 observed demand 最强、竞争最拥挤。** Tracked card figures 只是第三方跟踪样本，不是 TAM。AIX 将其作为 Secondary Job / 核心购买力能力。 |
| **J3 Keep Crypto → Liquidity** | 不卖 Crypto、保持敞口，同时获得可消费流动性 | 机制样本存在，但需求、规模、风险与合规 Unknown-heavy；作为未来选项。 |

这不是三个品牌桶。竞争发生在 `Job × Starting Money × Region × Purchasing-power Outcome` 的交叉点。

### Competition logic

- 用户购买的是 **Job / outcome**，不是 X、Y、custody 或某种产品架构；Card 只是 Spend Rail。
- **Direct gate** 必须同时满足：`same current region + same core Job + overlapping starting money + substitutable purchasing-power outcome`。同 X / Y / custody / rail 不是必要条件。
- Step 3 的 `Direct candidate` 是 evidence-level four-AND 判定；Step 4 再使用 Confirmed Direct / Conditional Direct / Adjacent / Rail Substitute 的竞争分类。仅作为例子，在 **PH stablecoin-starting J2 card segment**，RedotPay generic auto-convert card、Bitget Wallet Card、ether.fi Direct Pay 构成已确认的 player-to-player **Confirmed Direct set**；这不是全市场竞品榜单。
- **KAST Source Conflict 必须保留**：X2 confirmed；Y Unknown；Strategy Cluster Unknown；Money Account 保留。Step 2 的旧结论 `X2×C / S3` 已被 Step 3 新证据 supersede，不得继续当作 current mechanism。

## 3. Current AIX is not the target claim

### Current implementation baseline

- DTC provider custody，非 self-custody；已有受支持稳定币 Wallet。
- Wallet Balance 与 Card Balance 分离；Card purchase 的价值容器 **X1 confirmed**。
- Wallet→Card purchasing mechanism **Y Unknown**。
- 独立 Receive、Send / Swap runtime、Withdraw / Fiat rails、unified balance 均 **Unknown / 未闭环**。
- Account Role **最多 Account-adjacent**；当前不得称为 Money Account，也不得用目标态反写现状。

### Target choice

- **Core user**：把 stablecoin 当钱使用、或已经持有 stablecoin 并希望反复用于现实生活的用户。
- **Starting Money Proposal**：stablecoin-primary。依据来自 J1 对稳定价值资金的需求方向与 J2 的 stablecoin spend 证据；这是 market-level proposal，不是 current AIX constraint。Local fiat、salary、invoice、remittance 是重要 inflow；volatile crypto 是未来扩展。
- **Product Role**：Money Account target。只有真实形成 `Receive + Hold + Send + Spend + unified/same-balance equivalent`，才可赢得并对外使用 Money Account 身份。
- **Rail portfolio**：Card + Local QR/A2A + Bank/E-wallet。Card 必须可靠、低摩擦、费用透明，但它是必要 rail，不是定位。

## 4. Why this direction

1. **J2 Card-only 拥挤且功能层易被跟随——Inference。** 当前样本已出现 pre-fund、托管即时转换和 self-custody direct spend 等多种替代机制；“商品化”“低切换成本”“易 fast-follow”均是基于样本的市场推断，不是已证明事实。
2. **J1 可能建立 recurring money relationship——Inference。** Receive / Hold / Send / Spend、资金留存、持续 inflow 可能形成比偶发刷卡更深的用户关系，但 retention、switching cost 与 willingness-to-switch 尚未验证。
3. **Local rails 可能深化区域差异——Inference。** QR/A2A、Bank/E-wallet、合规与本地伙伴关系可能形成更深的场景覆盖和结构性防御，但 moat 与单位经济仍待验证。

## 5. PH as the proof market

**Decision：PH 仅是 `current evidence best-supported proof market`。** 它不是客观上的全球最佳市场，也不是因为 current AIX 已在 PH 才被选择。

当前选择理由：

1. 已观察到充分的 J2 Card 竞争；其战略含义是“再发一张卡”不足以构成定位（Inference）；
2. QR Ph、InstaPay、PESONet 与 e-wallet 提供成熟的 QR/A2A rail 证据；
3. Coins.ph 提供当前样本中清晰的 direct-at-merchant 路径；
4. GCash / Maya、bank/e-wallet 与 cashout 构成丰富替代路径。

**证据边界：** QR Ph / BSP 只证明 payment-rail maturity，不证明 stablecoin / crypto 使用量。

> **WS-1：`PH stablecoin-native Money Account + local purchasing-power loop` 只是 Low–Medium confidence candidate white space，绝不是 confirmed blue ocean。** KAST、Oobit、Plasma、Coins.ph 的资格、能力或本地闭环可能在验证期间收窄乃至关闭该空间。

## 6. One staged strategic path

> **A6 Local Purchasing-power Bridge（GTM wedge） → A3 Stablecoin Multi-rail Account（product form） → A1 Money Account-first（earned target state）**

这是一条路径，不是三个并行产品：先做深一个市场的本地购买力连接，以一个稳定币资金视图连接多 rail，只有在用户持续 Receive / Hold / Send / Spend 后，才赢得 Money Account 心智。

- **A2 Crypto Spend-first**：保留为必要能力，不作为定位。
- **A4 Self-custody Spend**：未来选项。
- **A5 J3 Credit / Collateralized Liquidity**：未来选项。

## 7. Current → Target roadmap

| Phase | 目标 | 关键验证 |
|---|---|---|
| **P0** | 关闭方向无关 Unknown：Y、Receive、Send/Swap runtime、Withdraw/Fiat rails、DTC boundaries、KYC/country、fee/FX/limits | 明确真实 implementation baseline 与合作方边界 |
| **P1** | 一个用户可理解的 money view；目标 UX 不要求手动 Wallet→Card prefund | first/repeat spend、funds retained、Card reliability / cost |
| **P2** | PH Local QR/A2A + Bank/E-wallet + stablecoin receive/spend loop | multi-rail use、local rail 是否增加频次、合规/结算/单位经济 |
| **P3** | Salary / invoice / remittance recurring inflow | recurring receive 与完整 Receive/Hold/Send/Spend 闭环；**只有此后才 earn Money Account identity** |
| **P4** | 可选扩展 volatile crypto、J3 credit、self-custody、更多地区 | 依据前序验证结果逐项决策 |

本路线不预设人为数字阈值；指标阈值需在产品、成本与基线得到验证后另定。

## 8. Management decisions now vs validation questions

### Decisions now

1. 市场边界 = consumer crypto/stablecoin → real-world purchasing power。
2. J1 Primary / J2 Secondary；J3 future。
3. Starting Money = stablecoin-primary market-level proposal。
4. Target Product Role = Money Account。
5. PH = current evidence best-supported proof market。
6. Rails = Card + Local QR/A2A + Bank/E-wallet；Card 不作为定位。
7. 路径 = A6 → A3 → A1。

### Validation questions

- J1 的用户规模、留存潜力与 willingness-to-switch 是否成立？
- 用户是否把资金留在 AIX，而不是每次临时充值？
- 用户是否真实使用多个 rails？Receive 是否形成 recurring inflow？
- Local rails 是否增加使用频次与场景覆盖？
- Fees、成功率、到账速度、退款/dispute、合规、结算与单位经济是否成立？
- KAST / Oobit / Plasma / Coins.ph 是否已闭合相同账户与本地 purchasing-power loop？
- Current AIX 的 Y、Receive、Send/Swap、Withdraw/Fiat rails、unified balance，以及 DTC capability boundaries 到底是什么？

## 10. Final management statement

管理层应把 AIX 的市场身份从“Crypto Card”提升为 **Stablecoin-native Everyday Money Account**：以 stablecoin-primary 用户为起点，在 PH 这个当前证据最充分的 proof market，用 Card + Local QR/A2A + Bank/E-wallet 建立现实购买力闭环；先以 A6 进入、用 A3 落地，只有在持续 Receive / Hold / Send / Spend 被用户行为证明后才赢得 A1 Money Account 身份。这个方向是已作出的战略选择，但 J1 需求、PH 白地、留存、防御性与单位经济仍必须通过验证，而不能被写成既成事实。

### Residual risks retained from Step 5 Grok review

1. **J1 quantification**：J1 demand 仍为 Medium，用户量化不足；J1 Primary 是带 Inference 的战略选择，不是已证明的 demand ranking。
2. **PH evidence bias**：PH 只是 current evidence 中最完整的 proof market；non-card 证据栈可能有采集偏差，不得外推为全球最优。
3. **WS-1 competitor closure**：WS-1 仍是 Low–Medium candidate；KAST / Oobit / Plasma / Coins.ph 可能在验证期收窄该空间。
4. **Staged-path interpretation**：A6→A3→A1 是 role-layered / staged；P1 unified balance 先于 P2 local rails，不得读成三个并行产品或矛盾交付顺序。
5. **Stablecoin-primary boundary**：stablecoin-primary 可与 salary / fiat inflow 共存，但不得漂移成已排除的 fiat-native neobank 策略。
